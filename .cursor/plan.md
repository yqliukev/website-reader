# Website Reader — plan

The product is an **agent extension** that reads web pages aloud (TTS), speaking only the core article.

## Goal

An extension that can:

- Read a web page with text-to-speech, and read only the core article.
- Provide a summary instead of reading word by word.
- Answer questions about the article, or related to the article, through basic web searches.
- Accept voice commands for starting, stopping, and similar controls.

## First useful version

- Smart TTS that reads only the core article.

## Later

- A summary in place of word-by-word reading.
- Answers to questions about the article, and to related questions, using basic web searches.
- Voice commands for starting, stopping, and similar controls.
